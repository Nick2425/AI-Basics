NeuroSoma: Technical Blueprint

The engineering blueprint: FastAPI Python backend, Three.js 3D WebGL viewport with 1:1 synchronized ViewCube, single-source-of-truth anatomical graph, and dual-mode audit engine.

Full System Architecture & Data Flow
Technical Stack & Architectural Rationale
FastAPI + Uvicorn Python 3.10+
Asynchronous, modern web framework hosting REST endpoints and serving static files from a single process.
Directly honors learner's 4-year Python expertise while providing sub-millisecond response times.
Three.js (WebGL) r128 CDN
Industry-standard 3D WebGL engine providing true 3D camera controls, raycasting, and transparency dimming.
Guarantees exact 1:1 rotation synchronization between the ViewCube and the anatomical camera.
Vanilla HTML5/CSS/JS ES6 Modules
Clean, lightweight frontend code without heavy frameworks or node_modules build friction.
Ultra-fast load time, 100% reliable local demo execution, and frictionless project setup.
Dual-Mode Concept Engine Local + LLM
Ground-truth concept graph matcher with an optional hook for live LLM API keys (Gemini / OpenAI).
Works 100% offline with zero API key requirement, while supporting live AI exploration.
Planned Component Architecture & File Tree

pip install -r requirements.txt
python app.py

app.py
FastAPI application hosting static file mounts, REST endpoints (`/api/anatomy`, `/api/audit`, `/api/what-if`), and server configuration.
Implements: prd.md > Screens and Layout
data/anatomy_graph.json
Single source of truth containing anatomical structures, innervation, clinical associations, and 3D geometric coordinates.
Implements: prd.md > 1. Viewport & Anatomical Navigation
engine/auditor.py & engine/what_if.py
Dual-mode semantic concept matcher that evaluates student notes, pinpoints unaddressed structures, and produces clinical what-if challenges.
Implements: prd.md > 3. Proactive Knowledge Gap Audit & 4. What-If Challenge
static/js/viewport.js
Three.js 3D scene builder, raycaster for part clicks, material transparency dimming, and 1:1 synchronized Autodesk ViewCube controller.
Implements: prd.md > 1. Viewport, ViewCube & Transparency Isolation
static/js/notes.js & static/js/terminal.js
Floating sticky note manager with subtle styling, left hierarchical tree controller, and modern terminal prompt with audit dialogue.
Implements: prd.md > 2. Sticky Notes & 5. Modern Terminal
